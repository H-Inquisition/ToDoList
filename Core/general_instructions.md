# Instructions
When starting the application a user is first required to provide a number of the port that will be used for the  
TcpListener.

After a prompt: "Please enter the port number" is displayed. Program will wait for the user to provide an input  
convertible to a 32-bit integer. In case that a user fails to provide such a value, program will display an appropriate  
warning and request to provide a number again.

Next program will start and await user input in form of the api commands/queries that are described in the  
[api_instructions](to_do_list_api/api_instructions.md) file.
